```
样本：18只股票一年的收盘价数据
口径：对表现的定义是形态命中后的20日累计收益率曲线进行均值以及中位数
```

# 观察：
- 中位数偏下
- 均值几乎等于零
- 正收益数量少于负收益数量，上涨比例始终低于 50%；明显的是正向极端收益的幅度大于负向极端收益，正向尾部更长

# 分析
均值主要由少数大幅正收益拉高，它回答的是平均幅度，本来就不回答“大多数怎样”；要看大多数情况应看中位数。这18只股票的命中段后面20天的累计收益曲线中位数一直为负，说明“表现”一般 
但是这并不能说明形态匹配程度与涨跌程度之间存在一定的负相关。当前没有随机窗口或未命中窗口作为对照，因此不能判断这种表现是否由形态提供了额外信息。
