# 思路概览
1. 遍历每一个窗口尺寸 W：
    1. 生成对应长度为 W 的模板原始序列
    2. 在 r_data 上，以W为窗口、步长step滑动：
        1. 遍历切片分段
            1. 在 3/13、12/13 附近带约束搜索两个断点
            2. 按断点分三段，三段在断点处共用同一个数据点，不留空白也不另用固定起点
            3. 每段各自拟合直线，提取平盘度、幅度比、斜率比
            4. 计算每个原始点到本段拟合线的距离，用这些距离的标准差表示段内波动；波动越大，扣分越多
            5. 计算相邻两条拟合线在断点处的高度差；高度差越大，说明图形越割裂，扣分越多
            6. 波动偏差和衔接偏差除以第一段上涨幅度，消除股价绝对高低的影响；原本的比例特征不需要再除
            7. 各项偏差加权求和，得到分数；分数越小越符合预期形态
            8. 记录并返回最佳分段分数
    3. 当前W窗口下所有分数，计算percentile
    4. 根据阈值筛选合格匹配
    5. 给匹配打上 window_size 标签，存入总结果
2. 所有 W 跑完后：合并重叠区间，同一物理区间只留 score 最优

# 新增的两项约束
1. 波动偏差：
    1. 对每一段，计算原始数据与拟合线的残差
    2. 计算残差的标准差，再除以 `abs(A1)`
    3. 三段的结果可以直接相加，也可以分别给权重
2. 衔接偏差：
    1. 在第一个断点，计算第一段拟合线终点和第二段拟合线起点的高度差
    2. 在第二个断点做同样计算
    3. 两个高度差取绝对值，除以 `abs(A1)` 后相加
    4. 衔接偏差过大可以直接判为不合格，其余情况参与加权打分
